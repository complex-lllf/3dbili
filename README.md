bilibili-3ds

A Bilibili video search and download client running on the Nintendo 3DS, developed with C++17 + libctru + citro2d.

---

📖 Project Overview

bilibili-3ds is a lightweight Bilibili client built for the Nintendo 3DS, focusing on two core features: video search and video download. The project does not include video playback capability (limited by the 3DS hardware decoding capability and libctru's media support). After downloading is complete, the .mp4 files can be taken out via the SD card and played offline on a PC or phone.

The project was generated by AI, aiming to demonstrate best practices for building a complete Homebrew application using libctru + citro2d, including complete modules such as HTTP requests, JSON parsing, graphical interface, background downloading, and CI building.

---

✨ Features

· 🔍 Keyword Search: Calls the Bilibili search API, enter keywords to get a video list
· 🖼️ Result List Display: Shows video titles, cover placeholders, uploaders, and view counts
· ⬇️ One-Click Download: Automatically calls the view → playurl APIs to obtain the MP4 direct link and download it
· 📊 Real-Time Progress Display: Shows a progress bar and downloaded/total bytes during downloading
· 📁 Local File Management: Scans downloaded .mp4 files on the SD card and displays them in a list
· ⌨️ On-Screen Keyboard Input: Uses the 3DS native Swkbd to enter search keywords
· 🎨 citro2d Graphical Interface: Dual-screen rendering (top and bottom), mixed touch and button interaction
· 🔓 No Login Required: Does not rely on any cookies or accounts, purely anonymous access
· 🤖 CI Auto Build: GitHub Actions automatically compiles and uploads .3dsx / .smdh artifacts
